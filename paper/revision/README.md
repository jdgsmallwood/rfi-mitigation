# Revised manuscript: additional analyses

These scripts reproduce the revision's numerical results from the same two
captures, flags, trained Haslam amplitude and 120-second windows as the main
notebook. They reuse its two tagged setup/toolkit cells, not a separate copy of
the mitigation implementation. Run in the installed project environment from
any directory; set `RFI_DATA_PATH` as described in the main README.

From the repository root, in this order:

```sh
python paper/revision/ranks.py
python paper/revision/channels.py
python paper/revision/halves.py
python paper/revision/single_pol.py
python paper/revision/track.py
python paper/revision/plot.py
```

For dense small matrices, setting `OPENBLAS_NUM_THREADS=1` and
`OMP_NUM_THREADS=1` before starting Python avoids thread overhead. The analyses
are offline and may take several minutes. Disk-result caching is disabled;
Astropy IERS auto-download is disabled to allow offline execution.

To redraw only the four additional scientific figures from the included
results, run only `plot.py`. It reads the committed CSV tables in `results/`,
not the notebook cache, and therefore needs no visibility captures. The
analysis scripts above recompute those tables from the captures.

`halves.py` tests ranks 0–10 independently in each 60 s half of all four
windows. `correlations.csv` records every half-window score; `adaptive_ranks.csv`
records the selected ranks and the combined 120 s image score. Exact ties
choose the smaller rank. No intermediate image archive is needed.
Figures 3, 6 and 8 and the array layout remain generated by the main notebook.
Figure 5 is typeset directly in the manuscript.

## Interpretation and checks

* The sweep's “unprotected” comparison retains Sun protection and shrinking,
  omitting only the Galactic sky template. The Sun-isolation test in the main
  notebook instead switches Sun protection off/on without shrinking.
* Track brightness is the cross-correlation-only dirty-image response at the
  predicted satellite position: Re(a* R a) - trace(R). It can be negative and
  includes astronomical/background/sidelobe contributions. Only positive values
  are plotted in dB; these are NOT measurements of isolated satellite power or
  mitigation suppression. The common reference is the Window 1 above-horizon
  mean. The ephemeris interpolation is checked against intermediate exact samples.
* Frequency trends include every channel except the affected channel, including
  the reference itself. Other channels can contain impulsive RFI; the fitted
  expectations are empirical comparisons, not independently known true images.
* Best fixed and half-window ranks are selected retrospectively against the
  corresponding clean-channel image. The purple stars use two equal 60 s halves
  in every window, including Window 4; the split does not use the satellite
  setting time. “Adaptive rank” in the legend describes this retrospective
  change in rank, not an automatic rank-selection method. Selecting the best
  rank for each half separately need not maximise the full-window correlation.
* Split results are combined as covariances weighted by retained integrations,
  then imaged and compared with the full-window reference. Averaging the two
  half-window correlation coefficients would be incorrect.
* The scripts assert agreement with the original Window 2 sweep/channel scan
  and reconstruct all 11 fixed-rank controls in each of the four windows from
  the split covariances (tolerance
  2e-5 in image correlation).

The included tables were produced during the October 2026 revision. Re-running
with a different numerical stack or IERS data can change final digits. All
plots are ordinary Matplotlib plots of measurements; no synthetic image content
is used. No runtime depends on the manuscript checkout or a chat artifact path.
